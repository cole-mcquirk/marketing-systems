# Marketing Systems

A collection of practical frameworks, processes, experiments, and tools for building better marketing systems.

This is a work in progress.

I'm interested in what happens when you look at marketing as a system rather than a collection of channels:

**strategy → audience → acquisition → conversion → lifecycle → measurement → improvement**

I'll use this space to document things I've learned, frameworks I've developed, and experiments I'm working on.
